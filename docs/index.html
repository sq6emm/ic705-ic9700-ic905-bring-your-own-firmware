    Transmission outside the amateur bands

    This release enables transmission outside the amateur radio bands. You alone are responsible for transmitting only on frequencies, with powers and in modes that your licence and your national regulations allow. Unlicensed or out-of-band transmission may be illegal and can interfere with other services.

    Includes the custom A/B bootloader

    Besides the main firmware, this release replaces the radio's small boot loader (the first 64 KiB of flash) with a custom A/B slot-toggle bootloader. The radio's own SD-card updater writes it once, when the update starts. The boot loader exists in a single copy: if power is lost during that write, the radio will not start and can only be recovered with an external flash programmer (e.g. CH341A, chip desoldered or clipped). Use a reliable power supply and do not interrupt the update.

    The firmware keeps two slots (A and B), as Icom's updater already alternates between them. The custom bootloader lets you switch to the other slot (e.g. back to the previous firmware):

    • IC-9700: hold POWER while connecting the DC supply, for about 5 seconds.
    • IC-705: at power-on keep holding POWER for about 3 seconds more, until the LED blinks.

    Installing any official Icom firmware afterwards restores Icom's own boot loader.

    How it works

    1. The page computes the MD5 of your file and checks it against the list of official Icom files.
    2. It decodes the firmware container (autokey transform + LZSS), exactly like the Python tools in the repository.
    3. It applies the release's patch file. A patch holds only the project's own code and data, plus references like “copy N bytes from address X of the official image” — no Icom firmware is distributed.
    4. It re-compresses the image, re-seals the container (MD5) and compares the MD5 of the result with the MD5 of the build that was tested on a radio. Only an identical file is offered for download.
    5. Install it with Icom's normal SD-card firmware update procedure, using this file instead of the official one.

    Privacy

    Your firmware file is processed entirely on your computer, in a background worker in this browser tab. It is never uploaded. The page loads only its own static files (HTML, CSS, scripts and patch descriptions) from this site; it uses no analytics, cookies, external fonts or third-party scripts. The “Translate this page” link opens Google Translate in a new tab only if you click it.

    You can also run the same process offline with the repository's icom_patch.py; both produce the same MD5.
